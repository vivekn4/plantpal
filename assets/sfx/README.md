# PlantPal sounds

Short blips synthesized for this app — no samples, no recordings, no
licence to track. `click.wav` is the tap blip, `bloop.wav` is the
watering sound, `sparkle.wav` plays on the adopt reveal. The extra
files (`water_bloop.wav`, `success.wav`, `sleep_chime.wav`,
`whoosh.wav`) are spare blips from the same synth set, kept for
later use. All sounds play on taps only and respect the sound toggle
in Settings.
